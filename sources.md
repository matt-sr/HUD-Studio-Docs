A source is where a field gets its value from the game. A field bound to a source updates as the game changes.

| Category       | What it is                     | Examples                     |
| -------------- | ------------------------------ | ---------------------------- |
| [Data Sources](sources/data_sources_intro.md) | the game's state right now     | `Stamina`, `Name`, `Downed?` |
| [Signals](sources/signals_intro.md) | something that just happened   | `Critical Hit`, `Kill`       |
| [Controls](sources/controls_intro.md) | the keys and buttons you press | `Held?`, `Keybind`           |

Pick one from the mode dropdown beside a field. Not every field offers all three.
