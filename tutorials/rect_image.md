Your own image file on a rectangle. Requires the **SimpleAssets** mod.

1. Put a PNG, JPEG or DDS file in `mods/hud_studio/assets/`.
2. In the [Blocks panel](../ui/blocks_tree.md)'s bottom toolbar, click **Add Block**.
3. With the block selected, click the **Add** button for `Rectangle`.
4. In `Value`, set `Material` to `Image`.
5. Pick the `hud_studio` folder, then your file.
6. In `Style`, set `Size` to fit the image.
7. Drag the image into place on the canvas.

A file added while the editor is open shows up once you select the node again.
